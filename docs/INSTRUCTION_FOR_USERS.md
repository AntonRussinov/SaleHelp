# Как подключиться к SaleHelp

Есть два способа начать работу: **только через Telegram** (без регистрации на сайте) или **через сайт с последующей привязкой Telegram**. Выберите удобный вариант.

---

## Вариант 1: Всё через Telegram (без сайта)

Подключить магазин можно полностью в Telegram — регистрация на сайте не требуется.

### Шаг 1. Откройте нашего бота

Перейдите по ссылке и запустите бота:

**[Открыть бота в Telegram →](https://t.me/SaleHelpProBot)**

(Или найдите в Telegram по имени: **@SaleHelpProBot**)

### Шаг 2. Получите API-токен в кабинете Wildberries

Чтобы бот мог работать с вашим магазином, нужен токен доступа к API WB.

1. Войдите в **личный кабинет продавца** Wildberries (аккаунт владельца профиля).
2. В правом верхнем углу нажмите на **название компании** → выберите **«Настройки»**.
3. Откройте вкладку **«Доступ к API»**  
   (прямая ссылка: [seller.wildberries.ru/supplier-settings/access-to-api](https://seller.wildberries.ru/supplier-settings/access-to-api)).
4. Нажмите **«Создать новый токен»**.
5. При настройке токена:
   - Выберите **категории данных**. Для работы SaleHelp нужны:
     - **Контент** — доступ к карточкам товаров (без этого подключение не пройдёт).
     - **Вопросы и отзывы** — чтение отзывов и отправка ответов (нужно для автоответов ИИ на отзывы).
     - Отметьте также **Маркетплейс** и **Статистика** — для уведомлений по заказам, продажам и отчётам.
   - Укажите **права**: отметьте, что токен **на чтение и на запись** (не только «Только на чтение») — иначе автоответы на отзывы работать не будут.
   - Выберите **срок действия токена** — **год**.
   - Укажите название токена (например, «SaleHelp»).
6. Сохраните токен: **WB покажет его только один раз**. Скопируйте его целиком и храните в надёжном месте.

> По истечении срока токен нужно перевыпустить в кабинете WB и заново указать его в боте или на сайте.

### Шаг 3. Подключите магазин в боте

1. В чате с ботом отправьте команду **`/addshop`**.
2. Бот попросит **WB API token** — вставьте скопированный токен одним сообщением.
3. Если токен подойдёт, бот запросит **название магазина** (любое, для вашего удобства).
4. После ввода названия магазин будет подключён, уведомления начнут приходить в этот чат.

Дополнительные команды в боте: **`/myshops`** — список магазинов, **`/cancel`** — отмена текущего действия.

## Вариант 2: Регистрация через сайт и привязка Telegram

Удобно, если вы хотите настроить бренд, правила для ИИ-ответов на отзывы и управлять всем из личного кабинета на сайте.

### Шаг 1. Зарегистрируйтесь на сайте

1. Перейдите на наш сайт и нажмите **«Регистрация»**.
2. Зарегистрируйтесь по email и паролю (или через Google, если доступно).
3. Войдите в личный кабинет.

### Шаг 2. Заполните данные и настройки

- **Данные по бренду** — название, тон общения и т.п.
- **Правила для ИИ** — как ИИ должен отвечать на отзывы (тон, ограничения, примеры).
- При необходимости **добавьте магазин** (магазин WB с API-токеном) через раздел магазинов. Токен WB получается так же, как в варианте 1 (кабинет WB → Настройки → Доступ к API; категории **Контент**, **Вопросы и отзывы**, **Маркетплейс** и **Статистика**).

### Шаг 3. Получите ссылку для привязки Telegram

1. В личном кабинете откройте **«Настройки»** (или раздел профиля).
2. Найдите блок **«Привязать Telegram»** и нажмите **«Получить код»** (или аналогичную кнопку).
3. Вам будет выдан **код привязки** (например, `ABC123`) и время его действия (обычно около 10 минут).

### Шаг 4. Подключите Telegram к аккаунту

1. Перейдите в нашего бота по ссылке (откроется чат с ботом):
   **[Открыть бота в Telegram →](https://t.me/SaleHelpProBot)**
2. В чате с ботом введите команду **`/link`** и через пробел вставьте код с сайта:
   ```
   /link ABC123
   ```
   (вместо `ABC123` — ваш код из личного кабинета).
3. Бот подтвердит привязку. Этот Telegram-чат будет получать уведомления по вашим магазинам, а настройки с сайта и из бота станут общими.

После привязки вы можете управлять магазинами и с сайта, и из Telegram.

---

## Что учесть

- **Безопасность токена WB:** никому не передавайте API-токен. Мы используем его только для работы с вашим магазином в рамках сервиса.
- **Один аккаунт — один пользователь:** привязка Telegram по коду связывает чат с вашим аккаунтом на сайте; все магазины этого аккаунта будут доступны и в боте.
- **Если что-то пошло не так:** при ошибке «Токен не подходит» проверьте, что токен скопирован полностью, создан в кабинете WB, и у него включены категории **Контент**, **Вопросы и отзывы**, **Маркетплейс** и **Статистика**. После создания токена категории изменить нельзя — нужно создать новый токен и повторить шаги.

Если остались вопросы — напишите в поддержку или в бота.
